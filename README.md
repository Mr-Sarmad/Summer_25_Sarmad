# 🌿 Summer Internship: Omics and Molecular Modelling Lab

Welcome to the official GitHub repository for the **Summer Internship Program** hosted by the *Omics and Molecular Modelling Lab*. This repository documents all the skills, topics, and projects covered during the internship, with hands-on experience in computational biology, bioinformatics, machine learning, and deep learning.

## 🧪 Internship Topics Overview

### 1. Environment & Setup
- Conda environment management
- GitHub for version control
- Python `sys` module for system interaction

---

### 2. Programming Fundamentals
- Input/Output operations
- Variables, Data Types & Type Casting
- Comments & Operators
- Conditional Statements & Loops
- Functions & Docstrings
- Error Handling (Try-Except, Specific Errors)

---

### 3. Data Structures & File Handling
- **Data Structures:** Lists, Tuples, Dictionaries, Sets  
- **File Handling:**
  - Reading/Writing FASTA files
  - Reading/Writing CSV files

---

### 4. Biological Programming Tools
- **Biopython:**
  - Sequence Reading & Manipulation
  - Sequence Writing & Operations

---

### 5. Data Processing & Manipulation
- **NumPy** for numerical operations
- **Pandas** for handling DataFrames
- Biological Data Preprocessing:
  - Encoding Techniques
  - Standardization & Normalization
  - Preprocessing for Deep Learning

---

### 6. Data Visualization
- **Matplotlib**, **Seaborn**, **Plotly**

---

### 7. Bioinformatics Applications
- GC Content Calculation
- DNA Sequence Validation
- Codon Usage Analysis
- Restriction Site Analysis
- SNP-Gene Expression Correlation
- Ligand Activity Prediction (Active/Non-Active)
- Promoter Activity Prediction

---

### 8. Biological Interpretation
- SNP Distribution Analysis
- Study of Evolutionary Pressures
- Literature-Based Biological Comparisons

---

### 9. Machine Learning
- **Feature Engineering**
  - Extraction & Construction
- **Supervised Algorithms:**
  - Linear, Logistic & Polynomial Regression
  - Decision Tree, Random Forest, SVM, XGBoost
- **Unsupervised Algorithms:**
  - Clustering, PCA, t-SNE
- **Model Evaluation Metrics:**
  - MAE, MSE, RMSE, R², Accuracy, Precision, Recall, Confusion Matrix
- **Tools:** `scikit-learn (sklearn)`

---

### 10. Deep Learning
- **Frameworks:** TensorFlow & PyTorch
- **Neural Network Architectures:**
  - ANN, CNN, GNN, 3D CNN, RNN
- **Training Concepts:**
  - Loss Functions, Backpropagation

---

### 11. Project Development & Management
- Scripting Best Practices
- Data Curation Pipelines
- GitHub Version Control
- Report Writing & Documentation

---
